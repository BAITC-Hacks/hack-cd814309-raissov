# FAQ-бот репетиции

Репозиторий команды raissov, задача репетиции хакатона.

Консольный бот, который отвечает на вопросы о репетиции хакатона: время, состав
команды, треки, сдача проекта, призы. Только стандартная библиотека Python,
никаких зависимостей. База ответов лежит в `faq.txt` — её можно править руками,
перезапускать ничего не нужно, кроме самого бота.

## Запуск

```
python3 bot.py
```

Выход — команда `exit` (или `quit`, `выход`) либо Ctrl+C.

## Пример диалога

```
FAQ-бот репетиции. Задайте вопрос, выход — exit или Ctrl+C.
> во сколько нам стартовать утром
Сбор в 9:30, старт ровно в 10:00, аудитория 204. Работаем до 18:00.
> сколько людей можно взять в команду
От двух до четырёх участников. Команду можно собрать прямо на месте, одиночкам поможем найти напарников.
> куда заливать готовый проект
До 17:00 залейте код в репозиторий и пришлите ссылку в форму на сайте. Потом пятиминутная защита перед жюри: демо и вопросы.
> какая погода завтра в Астане
не знаю
> exit
Пока!
```

## Как устроен поиск

1. `faq.txt` читается в список пар «вопрос — ответ». Каждой паре заранее
   считается набор ключевых слов: слова вопроса с весом 1.0, слова ответа —
   с весом 0.8 (они тоже помогают, но вопрос важнее).
2. Вопрос пользователя нормализуется: нижний регистр, `ё` меняется на `е`,
   пунктуация убирается, текст режется на слова. Слова короче трёх букв и
   служебные (`что`, `как`, `можно`, `когда`, ...) отбрасываются.
3. Каждое оставшееся слово сравнивается с ключевыми словами записи. Полное
   совпадение даёт вес целиком; если совпадает только начало слова, вес
   уменьшается — так `направления` находит `направление`, а `стартовать`
   находит `старт`. Это дешёвая замена стеммеру для русской морфологии.
4. Оценка записи — сумма найденных весов, делённая на число слов в вопросе,
   то есть доля вопроса, которую бот «узнал».
5. Берётся запись с максимальной оценкой. Если она ниже порога `THRESHOLD = 0.3`,
   бот честно отвечает `не знаю` вместо случайного ответа.

Пороги и веса собраны константами в начале `bot.py`: если ответы начнут
проскакивать мимо, поднимите `THRESHOLD`, если бот слишком часто молчит —
опустите.
